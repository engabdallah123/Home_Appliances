# تطبيق كاشير الموبايل (Cashier Mobile App)

تطبيق هاتف محمول مبني باستخدام **Flutter + Dart** مخصص لصاحب السوبر ماركت، لإدارة فواتير المشتريات والموردين ومتابعة مؤشرات المحل أثناء تواجده خارج المحل، مع نظام مزامنة سحابي ذكي (`Cloud Sync`) يربط التطبيق مع برنامج الـ POS Desktop المحلي دون المساس بعمله كبرنامج Offline.

---

## 📱 المميزات الأساسية في التطبيق

1. **تسجيل الدخول الآمن (JWT Authentication)**:
   - عزل المستأجرين (Tenant / Shop Isolation).
   - تخزين آمن لبيانات الجلسة والـ Token.
   - إمكانية تغيير رابط السيرفر السحابي بسهولة من شاشة الدخول أو الإعدادات.

2. **لوحة التحكم المباشرة (Dashboard)**:
   - إجمالي مشتريات اليوم والشهر.
   - تنبيه الفواتير المعلقة بانتظار المزامنة (`Pending Sync`).
   - بطاقات إحصائية لعدد الموردين والمنتجات.
   - قائمة بآخر الفواتير المسجلة مع شارات حالة المزامنة اللحظية.

3. **إدارة فواتير المشتريات (Purchases Management)**:
   - **تسجيل فاتورة شراء جديدة**:
     - اختيار المورد أو إضافته سريعاً.
     - اختيار الأصناف من كتالوج المحل بالباركود أو الاسم.
     - تحديد الكميات وأسعار الشراء وتواريخ الصلاحية.
     - احتساب الإجمالي والخصم والضريبة والمتبقي تلقائياً.
     - حفظ الفاتورة في السحابة بحالة `قيد المزامنة (Pending Sync ⏳)`.
   - **عرض وتصفية الفواتير**:
     - تصفية حسب: الكل، قيد المزامنة ⏳، تمت المزامنة ✅، فشلت المزامنة ❌.
     - البحث برقم الفاتورة أو اسم المورد.
   - **شاشة تفاصيل الفاتورة**:
     - جدول تفصيلي بالأصناف والكميات والأسعار.
     - بطاقة توضيحية لحالة المزامنة مع كاشير المحل وتاريخ سحبها.
     - إمكانية إعادة محاولة المزامنة (`Retry`) في حال وجود أي خطأ.

4. **إدارة الموردين (Suppliers)**:
   - استعراض قائمة الموردين وأرقام هواتفهم وعناوينهم وأرصدتهم.
   - إضافة مورد جديد فورياً وحفظه على السحابة.

5. **كتالوج المنتجات (Products Catalog)**:
   - استعراض الأصناف المتاحة في السوبر ماركت وأسعارها وأرصدتها الحالية.
   - البحث السريع بالباركود أو اسم الصنف.

6. **مراقبة الاتصال بالإنترنت (Offline Awareness)**:
   - شريط تنبيهي علوي عند انقطاع الاتصال (`Internet: Offline`).
   - حماية التطبيق من الانهيار عند عدم توفر الإنترنت.

## 🚀 بيانات الدخول الافتراضية (Default Credentials)

- **اسم المستخدم**: `admin`
- **كلمة المرور**: `123456`
- **كود الفرع**: `SHOP01`
- **رابط السيرفر الافتراضي**:
  - على محاكي الأندرويد (Emulator): `http://10.0.2.2:5100`
  - على الهاتف الحقيقي عبر الـ WiFi: `http://[IP_الجهاز_المضيف]:5100` (مثال: `http://192.168.1.100:5100`)

## 🛠️ متطلبات وطريقة التشغيل

1. **تثبيت حزم الـ Flutter**:
   ```bash
   cd Cashier_Mobile
   flutter pub get
   ```

2. **تشغيل الخادم السحابي أولاً (`POS.CloudAPI`)**:
   ```bash
   cd Cashier_System/POS.CloudAPI
   dotnet run
   ```
   *سيعمل الخادم السحابي على المنفذ `http://localhost:5100` ويوفر واجهة Swagger على `http://localhost:5100/swagger`.*

3. **تشغيل تطبيق الموبايل**:
   ```bash
   cd Cashier_Mobile
   flutter run
   ```

4. **تشغيل الـ Desktop POS ومزامنة الفواتير**:
   - شغّل برنامج الكاشير `POS.Desktop`.
   - افتح شاشة "المشتريات والموردين".
   - ستجد زراً جديداً في الأعلى: **[ مزامنة السحاب ☁️ ]**.
   - عند الضغط عليه (أو تلقائياً كل 5 دقائق في الخلفية)، سيقوم بسحب جميع الفواتير المسجلة من تطبيق الموبايل إلى قاعدة بيانات SQL المحلية وتحديث المخزون وإرسال تأكيد للسحابة لتصبح حالتها **Synced ✅** فوراً على هاتف صاحب المحل!
