# Home Appliances Cashier & POS System

نظام إدارة المبيعات ونقاط البيع والحسابات المتكامل للأجهزة الكهربائية والمنزلية (Home Appliances).

## محتويات المشروع (Project Structure)

المستودع يحتوي على مكونات النظام المتكاملة:

1. **`Cashier_System`**:
   - **POS.Desktop**: تطبيق سطح المكتب بنظام Blazor Hybrid (WPF) لإدارة نقاط البيع، المبيعات، الفواتير، التقسيط، وإعدادات المتجر.
   - **POS.WebAPI**: خادم الـ API والخدمات الخلفية بنظام Modular Monolith و Clean Architecture (.NET 10).
   - **POS.CloudAPI**: خدمات المزامنة السحابية لقواعد البيانات ومبيعات الفروع.
   - **الوحدات الأساسية**:
     - `Sales`: إدارة المبيعات، الفواتير المطبوعة A4 والعلامات المائية، وعقود التقسيط.
     - `Inventory`: إدارة الأصناف، الباركود، المنتجات بالرقم التسلسلي (Serials)، والعلامات التجارية (Brands).
     - `Purchases`: إدارة المشتريات ومردوداتها والموردين.
     - `Returns`: إدارة مرتجعات المبيعات.
     - `Expenses`: إدارة المصروفات وبنود الصرف.
     - `Shifts`: إدارة ورديات الكاشير وتقارير الإغلاق.
     - `Settings`: إعدادات المتجر، والترويسة والتذييل المخصص للفاتورة.
     - `POS.Licensing`: نظام التراخيص وحماية التفعيل.

2. **`Cashier_Mobile`**:
   - تطبيق الهاتف المحمول (Flutter / Dart) لمتابعة لوحة التحكم (Dashboard)، المنتجات، والمبيعات عن بُعد.

---

## متطلبات التشغيل (Requirements)
- **.NET SDK**: 10.0
- **Flutter**: 3.x+ (لتطبيق الهاتف)
- **SQL Server**: Express أو LocalDB أو Enterprise
- **Windows OS**: لتشغيل تطبيق الكاشير المكتبي (WPF)
